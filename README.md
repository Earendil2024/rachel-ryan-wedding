# Rachel & Ryan wedding website

A responsive, static wedding website for GitHub Pages.

## Preview locally

Open `index.html` in a browser. The site uses hash-based navigation (`#/travel`, `#/q-a`, etc.), so it works from a static host without server routing.

## Customize the RSVP and registry destinations

At the top of `script.js`, replace `RSVP_URL` and `REGISTRY_URL` with your event links. The navigation links and Home RSVP button use these URLs and open them in a new tab.

## Deploy to GitHub Pages

Upload the contents of this folder to the root of a GitHub repository, then select **Settings → Pages → Deploy from a branch** and choose the `main` branch and `/ (root)` folder.

Photos are loaded from Unsplash and the typefaces from Google Fonts, so those elements require an internet connection.
